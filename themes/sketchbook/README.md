# Sketchbook Theme

## Overview
The original hand-drawn sketchbook aesthetic theme with paper textures, rough edges, and animated transitions.

## File References
- Main styles: `../../theme-sketchbook.html`
- Base tokens: `../base/tokens.css`
- Shared utilities: `../base/mixins.css`

## Notes
- Preserves all visual effects including sketchy borders, hand-drawn animations, and ripple transitions
- Theme colors defined via CSS custom properties (`--accent`, `--ink`, `--bg`, etc.)
- Uses SVG filters for texture effects (loaded inline in HTML)

## Usage
Link in HTML:
```html
<link rel="stylesheet" href="themes/sketchbook/sketchbook.css">
```
