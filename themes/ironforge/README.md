# Ironforge Theme

## Overview
Steampunk/mechanical forge-themed UI with gear motifs and metallic aesthetics.

## File References
- Main styles: `../../theme-ironforge.html`
- Base tokens: `../base/tokens.css`
- Shared utilities: `../base/mixins.css`

## Notes
- Industrial design with brass/gold accents
- Gear animations and mechanical transitions
- Warm lighting effects with copper tones

## Usage
Link in HTML:
```html
<link rel="stylesheet" href="themes/ironforge/ironforge.css">
```
