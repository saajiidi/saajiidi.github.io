# Tactical Theme

## Overview
Military/green tactical UI theme with HUD elements.

## File References
- Main styles: `../../theme-tactical.html`
- Base tokens: `../base/tokens.css`
- Shared utilities: `../base/mixins.css`

## Notes
- Green-accented interface with tactical HUD overlays
- Dark background optimized for low-light conditions
- Includes telemetry overlay and scanning animations

## Usage
Link in HTML:
```html
<link rel="stylesheet" href="themes/tactical/tactical.css">
```
